CS student @ Hebei University of Science and Technology, focusing on C/C++ performance and algorithms.

## Projects

**[calc](https://github.com/VestJin/calc)** — A command-line calculator written in pure C.

- Hand-written recursive descent parser with operator precedence, parentheses, and right-associative exponentiation
- Supports variables (`x = 5`), math functions (sin, gcd, factorial…), constants, and `ans` for the last result
- Number base conversion (dec / hex / oct / bin) and a step-by-step calculation trace
- Equation solver: bisection for single-variable equations, Gaussian elimination for linear systems

**[repo2md](https://github.com/VestJin/repo2md)** — A fully client-side tool that turns local projects into a single Markdown document.

- Drop in a folder or a ZIP / TAR / GZ archive; generates a directory tree plus file contents, ready to paste into an LLM chat
- Everything runs in the browser — no file ever leaves your machine
- Automatically skips noise directories and detects binary / sensitive files

**[python_gui_demo](https://github.com/VestJin/python_gui_demo)** — A collection of small Python GUI tools I've built while learning.

- Each tool is a standalone script with its own README section
- More to come as I keep building
