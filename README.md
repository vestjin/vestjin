## Projects

**[repo2md](https://github.com/VestJin/repo2md)** — A fully client-side tool that turns local projects into a single Markdown document.

- Drop in a folder or a ZIP / TAR / GZ archive; it generates a directory tree plus file contents, ready to paste into an LLM chat
- Everything runs in the browser — no file ever leaves your machine
- Automatically skips noise directories like node_modules / .git, and detects binary files and sensitive files (keys, tokens, etc.)
